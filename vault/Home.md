# CommuteNity Web

> Community-driven transit routing for Metro Manila commuters.

#doc

---

## What is this?

Next.js 15 web app. Community maintains jeepney/bus/MRT routes + stops. Crowd-sourced data, vote-based moderation, offline-ready.

Stack: [[Tech Stack]] — Next.js 15 · Supabase · Tailwind v4 · shadcn/ui · MapLibre GL
