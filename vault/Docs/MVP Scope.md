## Transit Modes (MVP)

Jeepney · Bus · MRT/LRT · UV Express / FX · P2P Bus · Tricycle · Walking leg

Deferred: E-bike / pedicab · Grab / ride-hailing

---

## Explicitly Out of Scope

| Feature | Reason |
|---------|---------|
| Turn-by-turn live navigation | Real-time GPS; high complexity |
| Real-time vehicle location | Requires hardware integrations |
| Payments | Regulatory complexity |
| In-app chat / social feed | Not core to route-data mission |
| iOS app | Post-MVP; web-first |
| Admin dashboard UI | Supabase dashboard for MVP |

---

## Definition of Done

- Beta user finds valid Metro Manila commute without dev help
- Beta user submits route correction + sees it after community approval
- All five in-scope areas have passing happy-path acceptance criteria
